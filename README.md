# Probaho Remit — Titan Edition (Fixed Site)

Live demo: https://fahad3235.github.io/probaho-remit-titan/

AI-powered cross-border remittance and financial assistant — interactive demo
built for the 2026 Shenzhen International FinTech Competition (International
Track, Topic C: Cross-border & Student Finance Assistant).

## Demo contents

Static frontend demo (bundled). All rates, fees, provider comparisons, figures
and records shown in the app are **synthetic demonstration data** — no real
money moves.

## Run locally

Any static file server works, e.g.:

```sh
npx serve .
# or
python3 -m http.server
```

Then open http://localhost:3000 (or the reported port).
